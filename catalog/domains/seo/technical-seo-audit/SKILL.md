# Technical SEO Audit

Use to review crawlability, indexability and technical site health.

## Inputs
site/crawl export, sitemap, robots.txt, Search Console data and scope

## Procedure
define host and sample; inspect status codes, redirects, canonicals, robots directives, sitemap coverage, internal links, duplicate URL patterns, broken links, structured data and performance evidence where available; classify findings confirmed/likely/unverified; prioritize by impact, scale, confidence and effort

## Outputs
 evidence-backed issue register with examples, fixes and validation

## Quality checks
 state sample size and evidence limitations

## Boundaries
 never claim a full crawl without performing it; no production changes without approval.
